# 项目路线图 V1.0

## Phase 0: Navigation Session（当前）

**目标：让 Session 跑起来。**

**开发顺序：**
1. Navigation Session（状态机骨架）
2. Golden Flow（最小可用，JSON 文件）
3. Vision 集成（OCR + 页面识别）
4. Learning 模块（交互记录 + 地图更新）
5. 端到端 Demo（录屏离线演示）

**交付物：**
- 可运行的 Navigation Session
- 至少一个 App 的 Golden Flow
- 离线 Demo：输入录屏 -> 输出导航轨迹 + 引导文本 + Interaction Flow

## Phase 1: Growing Map

**目标：验证地图在真实导航中自动成长。**

**范围：**
- App：淘宝、京东、拼多多
- Task：退款、联系客服、查订单
- 多次导航后地图数据自动积累

**交付物：**
- 从真实导航中学到的 Flow 数据
- 地图完整度从 10% -> 30%
- 偏差检测和异常路径记录

## Phase 2: 产品化

**目标：构建可交付的产品。**

**交付物：**
- AI 眼镜端应用
- 语音引导（实时）
- 地图云端服务
- 开发者 API

## 数据成长路线

```
人工 Golden Flow          真实导航学习           AI 自动生成
    │                         │                      │
    ▼                         ▼                      ▼
10% 地图覆盖  ────────►  30% 地图覆盖  ────────►  80% 地图覆盖
                    人工审核                    人工审核
```

## 地图更新流水线

```
导航 Session
    │
    ├─► 交互事件记录（脱敏）
    │
    ├─► 与 Golden Flow 对比
    │   ├─ 匹配: 确认地图正确
    │   ├─ 偏差: 记录异常路径
    │   └─ 缺失: 记录新节点
    │
    ├─► 生成 Learned Flow
    │
    └─► 人工审核 → 更新地图
```

## 核心里程碑

| 里程碑 | 验证标准 |
|--------|---------|
| M1: Session 可运行 | 状态机能完成一个完整的导航循环 |
| M2: 首次 Golden Flow 导航 | 用预置地图走完一次退款流程 |
| M3: 自动学习验证 | 导航结束后自动生成 Flow |
| M4: 地图成长验证 | 多次导航后地图覆盖度提升 |
