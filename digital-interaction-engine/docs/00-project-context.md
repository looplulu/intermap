# Project Context V1.0

> Reality has Google Maps. The digital world has no map.

## 一、项目简介

本项目并不是一个 AI 眼镜项目。AI 眼镜只是第一个应用场景。

真正要构建的是一套新的基础能力：**Digital Interaction Engine（数字交互引擎）**。

它类似于现实世界中的 Google Maps 或高德地图：

- 现实世界中：GPS 负责定位，地图负责导航，汽车负责行驶。
- 数字世界中：AI 负责识别，Interaction Engine 负责定位，用户负责操作。

AI 不替用户操作，而是帮助用户理解数字世界，并完成数字世界中的导航。

## 二、V1.0 核心变化

**从"先建地图，再导航"变为"边导航，边建地图"。**

V1.0 不追求建立完整的数字交互地图。V1.0 的唯一目标：

> 验证数字交互地图是否能够在真实用户使用过程中自动成长。

导航本身就是地图构建过程。

## 三、产品定位

V1.0 不是 AI Agent。不是 AI 自动操作。不是数字助手。

而是：**Continuous Task Navigation（连续任务导航）**。

用户只需要说一次目标（如"我要退款"），之后系统自动进入任务模式，持续识别页面、持续定位、持续导航，直到任务结束。整个过程中无需用户反复询问"下一步"。

交互模式类似 **GPS 导航**，而不是聊天。

## 四、V1.0 四个核心能力

### 能力一：Task Recognition

用户表达目标。系统识别 Task，不关心具体 App。

### 能力二：Continuous Navigation

进入任务后，系统持续运行：

```
用户操作 -> 页面变化 -> AI识别 -> 定位当前节点 -> 自动播报下一步 -> 等待页面变化
```

### 能力三：Ground Truth + AI

- Ground Truth 负责：已有流程（确定性）
- AI 负责：页面变化、布局变化、版本变化、广告、弹窗（不确定性）

Ground Truth 永远不是 100%。AI 负责补足。

### 能力四：Interaction Learning

每一次导航都会自动学习。采集的不是屏幕或聊天内容，而是脱敏后的交互事件。形成 Interaction Flow，自动保存，地图不断成长。

## 五、为什么选择中老年人

老人不是不会点按钮。真正的问题有三个：

1. **不知道眼前是什么** — 这个按钮是什么意思？这个页面在干什么？
2. **不知道点击以后会发生什么** — 会不会扣钱？是不是自动续费？
3. **不知道出错怎么办** — 能不能返回？钱还能不能退？

老人真正缺少的是：**数字世界中的控制感**。

我们的产品理念不是 **Replace Human（替代）**，而是 **Guide Human（引导）**。

## 六、核心设计哲学

**不要为了 AI 去设计地图，而是为了地图去使用 AI。**

**不要先写数据库，先写 Navigation Session。**

真正的产品核心不是数据库，而是连续导航状态机。整个系统围绕一个 Session 运行。只要 Session 能跑起来，哪怕地图里只有 5 个节点，整个产品的交互就已经成立了。数据库只是这个状态机的知识来源。

## 七、Growing HD Map

地图不是一次性建立，而是 Growing HD Map。

- 初始：只有 Golden Flow
- 随着用户使用：不断补充、修正
- 最终成长为：完整地图

真正的数据来源不是工程师，而是真实用户。

## 八、V1.0 不做

- 自动点击 / 自动操作手机
- 完整互联网地图
- 所有 App / 所有 Task
- 长期用户记忆 / 商品记忆
- AI Agent

## 九、数据采集原则

不采集：完整录像、聊天内容、订单内容、个人信息。

仅采集：脱敏后的交互事件。

```
Task: Refund
App: Taobao
Node: Order Detail
Action: Refund Entry
Result: Success
Duration: 5s
Confidence: 0.94
```

所有数据围绕 Interaction，而不是用户。

## 十、V1.0 成功标准

1. **能否连续导航** — 用户说一次，系统一直带到结束
2. **能否自动定位** — 页面变化，无需再次询问，系统继续
3. **能否自动学习** — 一次导航，自动生成 Flow
4. **地图是否越来越完整** — 初始阶段 10%，一个月后 30%，半年后 80%

## 十一、V1.0 支持范围

- 平台：Android
- App：淘宝、京东、拼多多
- Task：退款、联系客服、查订单

## 十二、项目原则

1. **数据库负责确定性，AI 负责不确定性。**
2. **Flow 优先于 Page。**
3. **Task 优先于 App。**
4. **语义优先于文字。**
5. **地图记录稳定层，AI 处理动态层。**
6. **导航优先于执行。**
7. **建立用户控制感，而不是替代用户。**
8. **Session 优先于数据库。**
9. **导航即学习，学习即建图。**

## 十三、技术护城河

- **Digital Interaction Ontology**（数字交互本体）
- **Digital HD Interaction Map**（数字交互地图）
- **Navigation Session**（连续导航状态机）
- **Interaction Learning**（交互学习机制）
- **Growing Map Pipeline**（地图自动成长体系）

## 十四、一句话总结

V1.0 的目标不是构建一张完整的数字交互地图，而是验证数字交互地图能够在真实导航过程中持续学习、持续成长。
